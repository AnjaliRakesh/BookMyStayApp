# BookMyStayApp

## Hotel Booking Management System

This project demonstrates the implementation of a Hotel Booking Management System using Core Java and fundamental data structures.

The system is developed incrementally using different use cases.

---

## Use Case 1 (UC1): Application Entry & Welcome Message

### Goal
Establish a clear starting point for the application and display a welcome message.

### Actor
User runs the application from the terminal or IDE.

### Flow
1. User runs the application.
2. JVM invokes the `main()` method.
3. Application prints the welcome message.
4. Application terminates.

### Key Concepts Used
- Java Class
- `main()` method
- `static` keyword
- Console output using `System.out.println()`
- String literals
- JavaDoc comments
